# Prep: 5-Program Weekly Discipline

This repository contains the consistent weekly competitive programming and algorithmic solving. 5 programs a week.

## This Week's Programs

**1. 10,001st Prime**
Finds the 10,001st prime number by iterating and checking for prime factors.

**2. Largest Product in a Series**
Finds the thirteen adjacent digits in a given 1000-digit number that yield the greatest product.

**3. Special Pythagorean Triplet**
Calculates the product of the unique Pythagorean triplet ($a^2 + b^2 = c^2$) where $a + b + c = 1000$.

**4. Sum Square Difference**
Computes the mathematical difference between the sum of the squares of the first 100 natural numbers and the square of their sum.

**5. 2D Array - Hourglass Sum (HackerRank)**
Evaluates a 6x6 2D array to find and return the maximum sum of a 7-value hourglass subset.
